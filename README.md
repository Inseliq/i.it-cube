# IT-Куб · интерактивная платформа

React 19 + Vite 8 + React Router. Материалы занятий и проверочные тесты, подготовленные для размещения на GitHub Pages в `/i.it-cube/`.

## Запуск

```bash
npm ci
npm run dev
npm run test
npm run lint
npm run build
```

Для публикации в GitHub Pages: `npm run push` (перед запуском убедитесь, что правильный репозиторий настроен в git).

## Настройка тестов

Откройте `src/app/data/tests.map.js`. Настройки прописываются у каждого теста рядом с `title`, `questions` и `showAnswersAfterFinish`.

```js
{
  id: 'my-test',
  slug: 'my-test',
  path: '/test/my-test',
  title: 'Проверочная работа',
  description: 'Основы HTML',
  visible: true,
  maxAttempts: 2,           // 1, 2, 3... — конечное число; null/0 — бесконечно
  timeLimitSeconds: 900,    // секунды: 900 = 00:15:00; 0 — без ограничения
  passingPercent: 60,      // порог зачёта (0...100), по умолчанию 45
  showAnswersAfterFinish: false,
  version: 1,               // увеличить ТОЛЬКО для намеренного сброса прогресса
  difficulty: 2,
  questions: [ /* ... */ ],
}
```

Старое поле `repeat` поддерживается для тестов без `maxAttempts`: `true` означает без лимита, `false` означает одну попытку.

**Поведение**

- Попытка списывается сразу после нажатия «Начать тест». Перезагрузка страницы не предоставляет новую попытку.
- Ответы сохраняются при вводе в `localStorage`, а ход попытки автоматически возобновляется после обновления страницы/возвращения на тест.
- Дедлайн хранится как абсолютное время (`deadlineAt`) и не сбрасывается при закрытии вкладки или перезагрузке. Когда время вышло, уже введённые ответы автоматически оцениваются. При неограниченном времени таймер показывает «Без ограничения».
- После завершения сохраняются оценка, процент, отметка о зачёте, краткая история (последние 20 попыток) и ответы последней работы. Просмотреть ответы на вопросы можно только с `showAnswersAfterFinish: true`.
- Результат вычисляется на основе **баллов**, чтобы оценка и отображаемый процент совпадали для заданий разного веса.
- Изменив `version` у конкретного теста, преподаватель может намеренно начать новую локальную историю (для всех устройств при получении обновлённого сайта). Не меняйте `version` ради обычной правки текста: это сбрасывает лимиты и результаты.

### Важное ограничение защиты

Сайт является статическим SPA, без аутентификации и сервера. `localStorage` защищает от **обычной перезагрузки** и случайного повторного прохождения на том же устройстве, но пользователь способен очистить данные сайта, использовать другой браузер/устройство, изменить системные часы, открыть исходники с правильными ответами или изменить хранилище через DevTools. Строгие лимиты и достоверный журнал результатов требуют авторизации учащихся, ASP.NET API (или иного сервера), базы данных, серверного времени и проверки оценок на сервере. Не используйте браузерные ограничения как защиту официального экзамена.

## Структура

- `src/app/data/tests.map.js` — группы, тесты, вопросы и параметры попыток/времени.
- `src/app/utils/testSession.js` — устойчивое состояние теста, лимиты, проверка сроков и сохранение.
- `src/app/pages/test/index.jsx` — старт, прохождение и результаты теста.
- `src/app/pages/tests/index.jsx` — каталог тестов со статусами.
- `src/app/pages/test/test.logic.js` — проверка и оценивание ответов.
- `src/app/styles/` — адаптивный интерфейс платформы.
- `tests/testSession.test.js` — автоматические проверки ключевых сценариев.

### Возможные вопросы при настройке

Время вводится **в секундах**, отображается как длительность `ЧЧ:ММ:СС` с часами, минутами и секундами (например `5400 → 01:30:00`). Это не время суток.

`localStorage` не передаёт результаты преподавателю и не синхронизирует их между устройствами. Для централизованной проверки нужно подключить сервер.
